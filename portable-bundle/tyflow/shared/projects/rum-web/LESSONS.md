# rum-web 项目级错题本（LESSONS）

> 用途：记录本项目**反复出现 / 被人工纠正过 / 以后容易复犯**的问题，避免后续 AI 重犯。
> 写入门槛：同类问题重复 ≥ 2 次，或明显易复犯，才记。一次性问题留需求 `RETRO.md`。
> **开发前必读**：Step 4 识别到 rum-web 后，AI 先读本文件，把相关条目作为本次开发的约束。

## 升级规则

同一条反复命中时，在「状态」列升级：固化为 `RULES.md` 硬规则 / 补测试用例 / 降相关操作信任等级（`TRUST.md`）。项目无关的通用问题升 `RULES.md`，不要堆在这里。
