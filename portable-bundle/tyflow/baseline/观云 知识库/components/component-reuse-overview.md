# 组件复用总览

## 文档元信息

- 文档定位：组件复用层的总入口，负责把任务路由到复用流程或组件能力索引。
- 适用范围：组件选型、页面搭建、图表/抽屉/表格等通用能力接入。
- 推荐优先级：涉及组件复用时先读本文件。
- 冲突处理：若目标仓库已有稳定封装或真实用法，以目标仓库为准。
- 最后更新时间：2026-05-25

## 阅读顺序

1. 先读本文件，确认当前问题是“怎么选组件”还是“某个组件有哪些能力”。
2. 需要决策流程时，读 [component-selection-flow.md](./component-selection-flow.md)。
3. 需要查具体组件能力和导出项时，读 [component-library-index.md](./component-library-index.md)。

## 组件复用原则

- 新页面开发前先查目标项目里有没有真实使用或二次封装。
- 组件库文档只记录源码、类型、示例里能确认的信息，不把猜测写成结论。
- 表格、筛选、时间、页面容器、抽屉、空态、提示、拓扑能力优先复用。
- 图表优先使用组件库图表或项目已有 ECharts 封装，不把图表画成静态 SVG。

## 常见场景

| 场景 | 优先组件类型 |
| --- | --- |
| 业务列表页 | 页面容器 + 表格组件 |
| 多维筛选 | 筛选组件 |
| 时间范围查询 | 时间选择组件 |
| 简单详情展示 | 抽屉组件 |
| 指标图和趋势图 | 图表组件 |
| 拓扑、关系图 | 拓扑与图形组件 |

## 边界

- 这层文档解决“先复用谁”。
- 具体 props、导出能力和组件分组，交给 `component-library-index.md`。
