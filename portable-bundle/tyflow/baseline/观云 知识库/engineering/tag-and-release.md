# Tag 与发版规范

## 文档元信息

- 文档定位：说明功能开发完成后，什么情况下可以打 Tag、从哪里打 Tag、Tag 如何命名。
- 适用范围：功能开发完成、测试通过、准备发版、私有化发包、客户定制版本发布。
- 推荐优先级：涉及发版、打 Tag、版本命名时优先读取。
- 冲突处理：若与当前仓库实际发版流程、CI/CD 规则或管理员口径冲突，以真实项目流程为准。
- 最后更新时间：2026-05-26

## 核心原则

- Tag 不是从 `feature/xxx` 直接打。
- 公共版本 Tag 只从 `release/x.y` 打。
- 客户定制版本 Tag 只从 `custom/{客户简称}-{版本}` 或项目规定的定制分支打。
- 所有改动必须先完成开发、测试、Merge Request，再进入打 Tag 阶段。

## 功能开发完成后的标准流程

```text
feature/xxx 开发完成
-> Push
-> 发起 MR
-> Review 通过
-> 合并回 release/x.y
-> 测试通过
-> 从 release/x.y 打 Tag
```

## 1. 公共版本 Tag

### 适用场景

- `SaaS` 常规功能开发完成
- 公共 bugfix 合并完成
- `release/x.y` 分支已经通过测试、准备发版

### 打 Tag 前提

- 功能或修复已经合并回对应的 `release/x.y`
- 测试通过
- 发版内容已确认

### Tag 命名规则

```text
v<主版本>.<次版本>.<修订号>-<年年月月日日>-<序号>
```

示例：

```text
v2.14.0-250901-1
v2.15.0-250901-1
v3.9.0-250901-1
```

说明：

- 日期使用 `年年月月日日` 格式，例如 `250901`。
- 序号从 `1` 开始，按天循环。
- 同一天如果连续打多个公共版本 Tag，序号依次递增。

### 关键点

- 不要从 `feature/xxx` 直接打公共版本 Tag。
- 不要从本地临时分支直接打公共版本 Tag。
- 公共版本 Tag 的源头应该是目标 `release/x.y`。

## 2. 客户定制版本 Tag

### 适用场景

- 客户定制功能开发完成
- 定制版本测试通过
- 需要输出客户定制包

### 打 Tag 前提

- 定制功能已合并到目标 `custom/...` 分支或项目规定的定制发布分支
- 定制版本测试通过

### Tag 命名规则

```text
v<主版本>.<次版本>.<修订号>-<客户代号>-<年年月月日日>-<序号>
```

示例：

```text
v2.14.0-JiDiaoWangLuo-250901-1
v2.15.0-abc-250901-1
```

说明：

- 客户代号不能包含汉字。
- 日期使用 `年年月月日日` 格式，例如 `250901`。
- 序号从 `1` 开始，按天循环。
- 同一天如果连续打多个同类客户定制 Tag，序号依次递增。

### 关键点

- 客户定制 Tag 不应直接从公共 `feature/xxx` 分支打。
- 先确认当前项目的定制主分支和定制发布分支口径，再执行打 Tag。

## 3. Bugfix 场景

### 标准流程

```text
从问题对应 Tag 拉 bugfix/xxx
-> 修复
-> MR
-> 合并回对应 release/x.y
-> 测试通过
-> 打新 Tag
```

### 关键点

- bugfix 分支通常从出问题的 Tag 拉出。
- 新 Tag 不是在 `bugfix/xxx` 上直接长期保留，而是在修复合并回目标发布分支后产出。
- 多版本修复时，原则是从低版本向高版本传播，再分别打各自新 Tag。

## 4. 是否允许直接本地打 Tag

- 如果项目规定 Tag 只能由 CI/CD 或管理员创建，则开发者不要本地直接打。
- 如果项目允许手动打 Tag，也必须确认 Tag 的源分支是正确的发布分支。

默认按更严格口径理解：

- 保护分支：`main/master`、`release/*`、`custom/*`
- 保护 Tag：Tag 只能由 CI/CD 或管理员创建

## 5. 打 Tag 前检查清单

打 Tag 前至少确认：

1. 当前改动已经合并到正确的发布分支。
2. 当前分支不是 `feature/xxx` 临时开发分支。
3. 测试已经通过。
4. 版本号和 Tag 命名规则正确。
5. 当前 Tag 对应的是公共版本还是客户定制版本。
6. 当前项目是否要求由 CI/CD 或管理员创建 Tag。

## 6. 示例

### 公共版本发版

```text
release/3.9
-> 合并 feature/xxx
-> 测试通过
-> 从 release/3.9 打 V3.9.0
```

### 客户定制发版

```text
custom/ZhongXinYinHang-3.9.10
-> 合并定制功能
-> 测试通过
-> 打 V3.9.10-ZhongXinYinHang.1
```

### Bugfix 发版

```text
V3.9.0 出问题
-> 从 V3.9.0 拉 bugfix/fix-xxx
-> 修复并合并回 release/3.9
-> 测试通过
-> 打 V3.9.1
```
