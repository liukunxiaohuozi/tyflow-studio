# 观云 React 前端知识库术语表

## 文档元信息

- 文档定位：统一观云 React 前端知识库中的高频术语，降低人和 AI 的理解偏差。
- 适用范围：阅读、维护、接入 workflow skill、编写新规范时。
- 推荐优先级：当文档中出现同义词、缩写或多套叫法时优先参考本文件。
- 冲突处理：若术语定义与目标仓库真实实现冲突，以目标仓库命名为准。
- 最后更新时间：2026-05-25

## 核心术语

### 观云

- 本知识库中的“观云”指当前前端规范沉淀所服务的产品与研发体系。
- 如果某个仓库、设计稿或团队仍沿用“听云”命名，不视为冲突，只是历史命名差异。

### 听云

- “听云”通常出现在历史命名、组件库命名、品牌色说明、旧文档或包名中。
- 在本知识库语境里，可将“听云”理解为观云体系中的历史或兼容命名。

### Tingyun

- `Tingyun` 是“听云/观云”在代码、包名、目录名、组件名中的英文标识。
- 例如 `@ty-sdk/components`、`TyTable`、`TyDrawer`。

### 公司级规范

- 指对多个观云 React 前端项目都成立的通用基线。
- 当前优先入口是 `engineering/engineering-overview.md`。

### 项目级约定

- 指某个具体仓库自己的落地规则，例如目录结构、状态组织、局部封装方式。
- 在本知识库中，`engineering/project-standards-template.md` 当前按“模板”维护，不默认等同于任意真实项目。

### 项目级约定模板

- 指可以被具体项目拷贝、裁剪、补充的约定骨架。
- 作用是提供建议写法，不直接覆盖目标仓库自己的真实规范。

### 前端设计落地规范

- 指前端在写代码和做设计走查时应执行的规则。
- 当前优先入口是 `design/design-overview.md`。

### Figma 摘录

- 指从设计源文件提取出来的来源材料，用于追溯与交叉确认。
- 当前对应文档是 `design/figma-design-reference.md`。
- 它不是最终实现规范，不能单独替代落地规范。

### 组件复用参考

- 指围绕组件选型、二次封装、项目已有实现与组件库接入的经验总结。
- 当前优先入口是 `components/component-reuse-overview.md`。

### 主题源

- 指目标仓库中真正控制主题变量与视觉 token 的实现文件。
- 在现有文档里通常指 `theme.ts`、`css-var.css` 或同类主题文件。
- 当知识库规则与主题源冲突时，以主题源为准。

### 真实代码

- 指目标仓库中已经存在并实际运行的页面、组件、服务层、样式和配置。
- 它在多数任务里都比知识库中的抽象规则优先级更高。

### workflow skill

- 指后续可能接入本知识库的自动化前端工作流 skill。
- 推荐让 skill 先读取 `knowledge-base-entry.md`，再按任务类型选择具体文档，而不是一次性读完整个知识库。
