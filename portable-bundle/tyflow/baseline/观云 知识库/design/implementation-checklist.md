# 设计落地自检清单

## 文档元信息

- 文档定位：收敛设计规范在开发提交前的自检项和维护要求。
- 适用范围：视觉改动提交前、设计走查、样式治理。
- 推荐优先级：提交前快速过一遍。
- 冲突处理：若目标仓库有更严格自检流程，以目标仓库为准。
- 最后更新时间：2026-05-25

## 提交前自检

- 是否删除了非必要 `font-family`。
- 是否移除了可继承的默认字号与默认字色。
- 非默认字号、颜色、间距、圆角、阴影是否优先使用语义变量。
- 若存在硬编码色值，是否属于变量未覆盖场景。
- 新增变量是否已在主题源登记。
- hover / active / disabled / loading / empty 状态是否有一致反馈。

## 维护规则

- 主题改动先改主题源，再同步知识库。
- 不维护历史废弃值，不维护未落地的预研 token。
- 如果某条设计规则只在单一项目成立，应下沉到项目级约定，而不是继续留在通用设计规范里。
