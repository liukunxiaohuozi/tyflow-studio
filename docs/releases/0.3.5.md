# TingYun Studio 0.3.5 — 内部试用修复

## 本次更新

- 文字需求计划校验：Agent 输出约束与本地校验对齐。实施步骤必须声明非空的真实文件范围；纯验证动作写入测试用例。文字需求仍可不附文件，expectedFiles 不代表用户必须上传附件。
- 无效计划定向修正：仅对不合格的结构化计划自动进行一次只读修正，不自动开发，不伪造路径或填入全仓库通配符。持续失败时显示具体步骤/字段和准确的恢复建议，可在原任务重试。
- 检查更新：远程版本相同或更旧时不再额外请求下载清单；手动成功确认没有新版后弹出“已是最新版本”。网络/超时失败明确提示未能确认最新版本，不能伪装成最新版。
- 更新联网：使用 Electron 系统代理/PAC 通道，元数据检查使用较短超时，保留下载完整性校验、跨源凭据隔离和平台匹配要求。

## 如何更新

已有客户端：保存正确更新源和必要的仓库读取 Token，依次点击“检查新版本 → 下载更新 → 启用更新并重启”。若旧版下载失败，请重新检查后重试，或从本 Release 下载对应平台的 portable ZIP，完整解压后启动。任务及配置留在当前 OS 用户数据目录，不随 ZIP 分享。

macOS：Apple 芯片选择 arm64，Intel 选择 x64。内部包未做付费签名公证，首次安装/更新仍可能需要系统安全确认。旧版的启动检查可能静默失败，遇到没有提示时请手动检查或直接下载。

## 验证边界与未包含事项

本地全量回归已验证 22 个套件；计划修正和同任务重试、最新版/网络失败反馈经过真实 Electron/IPC 与确定性 CLI/网络夹具检查。远程 Windows/macOS CI 负责重新回归、打包和启动烟测，通过后发布三个平台包及完整性清单。真实 Codex、同事业务需求和 Mac 本机网络仍需内部试用，模拟传输不代表这些环境已验收。

本版未实现启动检查失败自动重试、下载断点续传/自动重试或失败时直接重试下载按钮；也没有放宽三道硬闸、自动执行开发或新增 GitLab/禅道外部写入。
