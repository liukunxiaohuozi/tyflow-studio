# TingYun Studio 0.3.11

## 本次更新

- 新建文字需求和小 Bug 默认使用 L1 轻量修改，直接保存到当前项目目录、当前分支；不单独评估、不安装依赖、不自动启动项目或测试浏览器。开发完成后可在原有浏览器查看热更新。
- 标准开发继续支持需求评估、计划确认、独立工作区和并行任务。未选择自动化测试时进入人工查看；自动化测试由用户明确选择。
- 文字需求支持上传包含 Markdown、TXT 和设计图片的 ZIP，也可分别上传文件。不再要求先提供 HTML 原型；误从 OpenDesign 入口上传文档/图片包时自动切换到文字需求。
- 导入资料保留文件清单，支持本地安全预览、移除和中文 ZIP 文件名。评估会获得资料目录及文档、图片清单。现有 HTML 原型包继续受支持。暂不包含 PDF/Office 解析或 Figma 链接抓取。
- 计划、用例和补充信息使用抽屉展示；改进测试证据文件识别、验证未完成状态，以及网络中断、评估只读访问失败时的提示与阶段恢复。
- 页面自动化可按需使用专用测试浏览器；不会自动接管个人浏览器或复制登录凭据。缺少测试环境不再被伪装为测试通过。

## 同事怎么更新

1. 先保存未保存的内容，并完成或停止运行、排队中的任务。
2. 打开「开发配置 → 客户端更新 → 检查新版本」。
3. 确认发现 0.3.11，下载完成后点击启用/重启更新。

也可从本 Release 下载对应的 portable ZIP。Mac Apple Silicon 选 `macOS-arm64`，Intel 选 `macOS-x64`；Windows 选 `Windows-x64`。解压到新目录，保留原版本目录。配置和任务历史继续使用本机数据目录。

内部 macOS 包未做付费开发者签名公证，系统仍可能要求在「隐私与安全性」中人工确认打开；本次不修改系统安全设置。已有冻结任务保留原工作区，不会自动搬回项目原目录。主程序更新不等于业务代码自动合并。

## 验证与边界

已完成相关导入、服务编排、L1、安全路径与持久化回归，以及 Windows 实际安装包的上传、预览、保存、评估资料传递检查。完整平台测试与构建结果见本版本 GitHub Actions。CI macOS 冒烟不替代同事真实项目、登录环境的验收。
