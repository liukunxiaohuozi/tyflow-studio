# TingYun Studio 0.3.12

## 修复客户端更新失败

修复检查或下载更新时出现 `Redirect was cancelled` 的问题。GitHub 发布资源会返回重定向；旧版使用的 Electron fetch 接口在手动重定向模式下直接取消请求，导致无法读取清单或下载更新包。

改用能暴露重定向响应的 Electron 请求接口，继续由更新器逐跳处理。保留 HTTPS、跳转次数上限、跨域不转发 Token、禁用会话 Cookie、平台/大小/SHA-256/ZIP 校验，以及中止和部分文件清理。网络栈继续使用系统代理，不修改全局网络或系统安全设置。

Windows、macOS 发布流程新增真实 Electron 网络回归，覆盖多次跳转、清单读取、ZIP 下载、凭据隔离、超时与取消，不再仅靠模拟 fetch 的测试判断更新链路可用。

同时修复手动安装新版后可能被旧更新记录跳回旧版的问题。新版会接管过期选择记录，保留旧版备份；主动选择「回退上一版本」仍然有效。

## 已受影响的旧客户端：这次需要手动安装

0.3.5 至 0.3.11 的更新器也包含这处缺陷，不能依赖其内置更新按钮完成自我修复。

1. 保存未保存内容，完成或停止正在运行、排队的任务，彻底退出 Studio（Mac 使用 ⌘Q）。
2. 在本发布页下载匹配的 portable ZIP：Mac M 系列芯片选 `macOS-arm64`，Intel Mac 选 `macOS-x64`，Windows 选 `Windows-x64`。
3. 解压到新目录，打开里面的 Studio；Mac 也可将新应用放入「应用程序」。保留旧版本目录作为备份。
4. 确认客户端版本为 **0.3.12**。配置、凭据及任务历史仍使用原来的本机数据目录，不要删除该目录。
5. 在「开发配置 → 客户端更新」检查更新。当前为最新版本时应显示已是最新版本；下一次有更高版本发布时，再验证下载和重启升级。

内部 Mac 包仍未做付费开发者签名公证，首次打开可能仍需系统人工确认；此修复不会关闭系统安全机制。手动安装修复版一次后，后续版本可继续使用内置更新。

本版保留 0.3.11 的轻量开发和「需求文档＋设计图片 ZIP」导入能力，不重新执行任何已有开发任务。
