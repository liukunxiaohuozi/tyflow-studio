# TingYun Studio 0.3.13

## 下线未形成闭环的禅道关联

- 移除新建任务中的禅道关联区、刷新列表及打开条目入口。
- 移除开发配置中的「禅道连接」页签、账号凭据及产品/项目映射表单。
- 停用客户端的禅道目录、导航和连接检测调用；新任务不再接受禅道关联。
- 旧任务历史及已有关联信息兼容保留，不清空历史数据。旧连接配置不再生效，也不会阻塞其他配置的保存。
- 开发、测试、Git、客户端更新和企业微信通知功能保留，不新增自动回写或外部操作。

## 从 0.3.12 更新

1. 打开「开发配置 → 客户端更新」，点击「检查新版本」，应发现 **0.3.13**。
2. 下载更新；保存未保存内容，完成或停止运行中和排队的任务。
3. 点击启用更新并重启，确认版本为 **0.3.13**。

配置和任务历史继续使用原本的本机数据目录，不要删除该目录。

若还在使用 0.3.5～0.3.11，其旧更新器包含重定向兼容缺陷，这次请从本发布页手动下载对应平台的 portable ZIP，彻底退出旧客户端后解压打开新版。Mac M 系列选择 `macOS-arm64`，Intel Mac 选择 `macOS-x64`，Windows 选择 `Windows-x64`。

Mac 包仍是未做付费签名公证的内部包，首次打开或更新后可能需要在系统隐私与安全性中人工确认；本版不会关闭或绕过系统安全机制。
